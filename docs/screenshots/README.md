# Capturas de pantalla

Esta carpeta contiene las capturas de pantalla utilizadas en el README principal.

## Capturas necesarias

1. **dashboard.png** - Vista del dashboard con estadísticas por periodo
2. **historial.png** - Vista del historial con búsqueda y filtros
3. **formulario.png** - Vista del formulario de registro multi-plataforma

## Cómo agregar capturas

1. Toma las capturas de pantalla de la aplicación en funcionamiento
2. Guárdalas en esta carpeta con los nombres exactos mencionados arriba
3. Formato recomendado: PNG, 1200px de ancho
4. Optimiza las imágenes antes de subirlas (usa https://tinypng.com)

## Resolución recomendada

- Ancho: 1200-1400px
- Calidad: Alta (sin comprimir demasiado)
- Formato: PNG con transparencia o JPG (90% calidad)
